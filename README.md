# ObraFácil

MVP de sistema web de gestão de obras para pequenos empreendedores da construção civil.
Permite cadastrar obras, registrar receitas e despesas e consultar o resumo financeiro
(receitas, despesas e saldo) pelo celular.

## Tecnologias

Python 3.12, Django 5.2 LTS, Bootstrap 5.3, PostgreSQL (produção) e SQLite (desenvolvimento).

## Status

Em desenvolvimento (projeto acadêmico de Análise e Desenvolvimento de Sistemas).
